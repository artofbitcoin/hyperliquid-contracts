# Périmètre de confiance

La sécurité du pont combine le code EVM, les signataires autorisés et le mécanisme qui transmet les décisions de Hyperliquid.
Un contrat correct ne peut compenser une clé compromise ou une donnée source incorrecte.
Les rôles administratifs, possibilités de mise à jour et procédures d'urgence doivent être documentés avec le code.
Les intégrateurs doivent aussi distinguer confirmation EVM, acceptation du bridge et finalité économique du système source.
Ce parcours est une lecture pédagogique, pas un audit ni une attestation de déploiement.
Aucune installation, compilation, transaction ou exécution n'a été réalisée.
La suite de tests du dépôt reste la référence pour vérifier les invariants implémentés.
