# 8 — Solvabilité et tokens atypiques

La somme des créances reconnues doit rester couverte par les actifs effectivement contrôlés par le pont.
Un token à frais peut faire recevoir moins que le montant demandé ; un token rebasant peut modifier le solde sans transfert.
Le pont doit mesurer le delta réel lorsque le modèle du token n’est pas strictement standard.
Les décimales ne prouvent ni la valeur économique ni la convertibilité vers l’actif d’origine.
Un wrapper Bitcoin ajoute des hypothèses sur dépositaire, preuve de réserve, mécanisme de mint et droit de rachat.
Ces risques ne sont pas supprimés par un quorum Hyperliquid valide.
Les limites par actif et les pauses sélectives réduisent le rayon d’un incident.
